## 🔥 How XSS Works

XSS happens when a vulnerable website **returns attacker controlled JavaScript to a user's browser**.

**Simple flow:**
`Attacker Injects JS → Website Returns It → Victim Browser Executes It`

The attacker can then potentially **act as the victim, access sensitive data, or abuse their privileges**.
