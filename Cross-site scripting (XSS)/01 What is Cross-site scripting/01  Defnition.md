##  Cross-Site Scripting (XSS)

XSS is a web vulnerability where an attacker injects **malicious JavaScript** into a website, causing it to execute in another user's browser.

###  Impact

* Perform actions as the victim
* Access sensitive data
* Abuse victim privileges

**Simple idea:**
`Attacker Input → Vulnerable Website → Victim Browser → JavaScript Executes`

###  Types

* **Reflected XSS**
* **Stored XSS**
* **DOM-based XSS**
